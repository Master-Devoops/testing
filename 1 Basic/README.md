# 1 Basic

This folder is the starting point project created with React + Vite.

## What happens in this folder

- Shows a simple React page with Vite/React logos and basic styling.
- Demonstrates `useState` using a counter button.
- Serves as the baseline structure before auth and routing features were added in later folders.

## Run this project

```bash
npm install
npm run dev
```

## Main files

- `src/App.jsx`: main UI and counter logic.
- `src/App.css`: page styling.
- `src/main.jsx`: React app entry point.
